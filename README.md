# Shopping Cart UI

## Overview
This project is a minimal shopping cart UI that allows users to add, view, and remove items from their cart.

## CI/CD Pipeline
This project uses GitHub Actions for CI/CD. The pipeline is configured to run tests and deploy the application to Vercel on every push to the main branch.

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`
3. Run the application: `npm start`

## Features
- Add items to the cart
- Remove items from the cart
- View items in the cart

## Technologies
- React
- GitHub Actions
- Vercel for deployment
